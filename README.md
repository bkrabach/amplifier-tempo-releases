# Amplifier Tempo downloads

Download [Amplifier Tempo for macOS](https://github.com/bkrabach/amplifier-tempo-releases/releases/latest/download/Amplifier-Tempo-macOS.zip) — no GitHub sign-in required.

Tempo is a native companion for your existing Amplifier Unified host: menu-bar status, an optional glass avatar, desktop notifications and quick replies. It does not install or restart the host. Requires macOS 13 or later; the universal app supports Apple Silicon and Intel.

## Install

1. Download and unzip the app.
2. Quit any older Tempo build, then move **Amplifier Tempo.app** into your Applications folder and open it.
3. Open **Settings → Connection** and connect to your compatible Unified host. Browser approval is available on hosts that support device pairing; older compatible hosts can use the manual connection option.

Public downloads are Developer ID signed and Apple-notarized. Moving from an old ad-hoc preview may require one Keychain approval. Signed upgrades retain saved settings and credentials. Use **Check for Updates** from Tempo's menu; automatic checking is optional.

[Release notes and checksums](https://github.com/bkrabach/amplifier-tempo-releases/releases/latest) accompany each version. The signed update feed is [appcast.xml](https://github.com/bkrabach/amplifier-tempo-releases/releases/latest/download/appcast.xml).

Application source is maintained separately in a private repository. This repository contains public distribution files only.
