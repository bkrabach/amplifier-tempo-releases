# Amplifier Tempo downloads

This repository hosts signed, notarized Amplifier Tempo releases and the signed automatic-update feed. Application source is maintained separately in a private repository.

No public app release is available yet. Apple signing and installation qualification must complete before publication. Unsigned development previews are not distributed here.

When available, download **Amplifier-Tempo-macOS.zip** from [Releases](https://github.com/bkrabach/amplifier-tempo-releases/releases). The stable update feed will be `https://github.com/bkrabach/amplifier-tempo-releases/releases/latest/download/appcast.xml`.
